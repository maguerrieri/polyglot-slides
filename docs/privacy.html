Privacy policy

Effective 2026-09-04. Applies to the Polyglot Slides add-on for Google Slides ("the add-on"), published by sprue.works ("the developer").

Summary

The add-on runs entirely inside Google's Apps Script platform. It has no server of its own and collects no personal data. Google Translate is the only external recipient of your presentation text: the add-on's own code reads and edits the open presentation, and transfers nothing anywhere else, and Google Translate receives only the text you ask it to translate. The sections below state, in Google's terms, what Google user data the add-on accesses, how it uses that data, with whom it shares it, how it protects it, and how long it keeps it.

What Google user data the add-on accesses

The add-on requests two Google permissions (OAuth scopes):

  • presentations.currentonly — view and manage the presentation the add-on is open in. Under this scope the add-on accesses the text and layout (position and size) of the slide elements you select, or of the slide or slides you choose to duplicate, in that one presentation. It cannot see any other file in your Drive.
  • script.container.ui — show its menu and sidebar inside Google Slides. This scope grants no access to user data; it only lets the add-on draw its interface.

The add-on does not access your Drive file list, Gmail, Calendar, contacts, or Google account profile, and it does not request any scope that would allow it to. It does not access your email address or name.

How the add-on uses Google user data

The add-on uses the text it reads for one purpose only: to produce translated copies of the selected elements or slides and insert them into the same presentation, when you explicitly run one of its actions from the sidebar or the Extensions menu. It reads layout only to place the copies next to the originals. Nothing is read until you start an action, and no data is used for any other purpose.

Polyglot Slides' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is used only to provide the add-on's translation features to you, is never sold, and is never used for advertising.

With whom the add-on shares, transfers, or discloses Google user data

  • Google Translate. The text you choose to translate is transferred to Google Translate through Apps Script's built-in LanguageApp service, which is subject to Google's privacy policy. This is the only transfer the add-on makes. Only the text in the selection or slides you chose is sent, and only when you run an action.
  • No one else. The add-on does not share, transfer, or disclose Google user data to the developer or to any third party. It has no analytics, no trackers, no advertising, and no external servers. Apart from the Google Translate transfer above, the add-on's only communication is between its own sidebar and its own Apps Script code inside Google's platform, which is how it reads and edits your presentation; that traffic stays within Google's platform and runs under your own Google account.

How the add-on protects Google user data

  • The add-on runs entirely inside Google's Apps Script sandbox, on Google's infrastructure, under the permissions you granted. The developer operates no server, database, or storage of any kind, and has no access to any user's presentation content or translations.
  • Your presentation text is handled in memory for the duration of a single run and is transmitted only between Google services (Apps Script and Google Translate), inside Google's infrastructure, which encrypts data in transit.
  • The only value the add-on stores is your language selection, kept in your own Google account's Apps Script user properties. Google scopes that store to your account and to this add-on; the add-on reads it only when you run it, and the value is never transmitted to the developer or to any third party.
  • The add-on's source code is public at github.com/sprue-works/polyglot-slides, so the behavior described here can be verified.

AI/ML model training. The add-on does not use Google user data to develop, improve, or train generalized artificial intelligence or machine learning models. It does not retain the data needed to do so.

Retention and deletion of Google user data

  • Presentation content and translations are not retained after a run completes. The add-on keeps no copy of your presentations, your selected text, or the translations it produced; the translated copies exist only inside your presentation, where you control them.
  • Your language selection (a list of language codes, no personal data) is retained in your account's Apps Script user properties so the sidebar remembers it. It is overwritten each time you run an action and is retained until you uninstall the add-on or revoke its access at myaccount.google.com/permissions, after which the add-on can no longer read it.
  • Execution logs. Google may keep standard Apps Script execution logs (timestamps, error messages) for the add-on's script project, as it does for any add-on, and retains them under Google's own policy. These do not include your slide content or translations.

To ask a question or make a request about your data, contact help@sprue.works.

Children

The add-on is intended for teachers and other adults. It does not knowingly collect any information from anyone, including children.
