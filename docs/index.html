Polyglot Slides

A Google Slides add-on that duplicates what you select — a few boxes, a slide, or the whole deck — with the text translated into the languages you choose.

What it does

  • Duplicate selection per language — one translated copy of the selected cluster per language, stacked below the originals. Highlighted text inside a box gets the translations appended as new paragraphs.
  • Duplicate current slide per language — a translated copy of the slide per language, right after it.
  • Duplicate all slides per language — the same for every slide, in order.

Languages are picked once in the sidebar and remembered for you. Translation is Google Translate, through Google's own Apps Script service — nothing to sign up for, no cost.

Install

Install from the Google Workspace Marketplace, then open any presentation and look under Extensions → Polyglot Slides. (Listing link is added here once the listing is live — see the project README until then.)

Privacy

The add-on only reads and edits the presentation it is open in, only when you run it, and keeps nothing but your language preferences. Full details: Privacy policy · Terms of service.
