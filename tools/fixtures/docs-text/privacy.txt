Privacy policy — Polyglot Slides ← Polyglot Slides Privacy policy Effective 2026-09-12. Applies to the Polyglot Slides add-on for Google Slides ("the add-on"), published by sprue.works ("the developer"). Summary The add-on runs entirely inside Google's Apps Script platform. It has no server of its own and collects no personal data. Google Translate is the only external recipient of your presentation text: the add-on's own code reads and edits the open presentation, and transfers nothing anywhere else, and Google Translate receives only the text you ask it to translate. The sections below state, in Google's terms, what Google user data the add-on accesses, how it uses that data, with whom it shares it, how it protects it, and how long it keeps it. What Google user data the add-on accesses The add-on requests two Google permissions (OAuth scopes): presentations.currentonly — view and manage the presentation the add-on is open in. Under this scope the add-on accesses the text and layout (position and size) of the slide elements you select, or of the slide or slides you choose to duplicate, in that one presentation. It cannot see any other file in your Drive. script.container.ui — show its menu and sidebar inside Google Slides. This scope grants no access to user data; it only lets the add-on draw its interface. The add-on does not access your Drive file list, Gmail, Calendar, contacts, or Google account profile, and it does not request any scope that would allow it to. It does not access your email address or name. How the add-on uses Google user data The add-on uses each kind of Google user data it accesses for one specific purpose, in service of a feature you run yourself from the sidebar or the Extensions menu. No presentation content is read until you start an action (opening the sidebar reads only your saved language selection, to show it), and no data is used for any purpose other than the one listed for it here. Text of the slide elements or slides you select ( presentations.currentonly ) Used for: sending to Google Translate, then writing the translation back into the same presentation: as a new copy of the element or slide, or, when you highlight a run of text inside one box, as new paragraphs appended at the bottom of that same box. Feature: Duplicate selection, Duplicate current slide, and Duplicate all slides per language. Layout of those elements: position and size ( presentations.currentonly ) Used for: placing the translated copies next to the originals so they keep their arrangement. Feature: the same three duplication actions. Your saved language selection (Apps Script user properties) Used for: pre-selecting your languages in the sidebar and applying them when you run an action from the Extensions menu. It is a list of language codes and contains no personal data. Feature: the language selection. Menu and sidebar display ( script.container.ui ) Used for: drawing the add-on's menu and sidebar inside Google Slides. This capability reads no user data, and no data leaves the editor through it. Feature: every action. That list is complete: the add-on has no other use for Google user data. It does not use Google user data for advertising, does not sell it, does not use it to build user profiles, does not use it to determine creditworthiness or for lending purposes, and does not use it to develop, improve, or train generalized artificial intelligence or machine learning models. No person at sprue.works reads it: the developer never receives it, as the sharing section below explains. Polyglot Slides' use of information received from Google APIs adheres to the Google API Services User Data Policy , including the Limited Use requirements. Data obtained through Google APIs is used only to provide the add-on's translation features to you, is never sold, and is never used for advertising. With whom the add-on shares, transfers, or discloses Google user data Google Translate. The text you choose to translate is transferred to Google Translate through Apps Script's built-in LanguageApp service, which is subject to Google's privacy policy . This is the only transfer the add-on makes. Only the text in the selection or slides you chose is sent, and only when you run an action. No one else. The add-on does not share, transfer, or disclose Google user data to the developer or to any third party. It has no analytics, no trackers, no advertising, and no external servers. Apart from the Google Translate transfer above, the add-on's only communication is between its own sidebar and its own Apps Script code inside Google's platform, which is how it reads and edits your presentation; that traffic stays within Google's platform and runs under your own Google account. How the add-on protects Google user data The add-on requests two OAuth scopes. Google classifies presentations.currentonly as non-sensitive and script.container.ui as sensitive . Data handled under either scope is protected by the following mechanisms. Encryption in transit. Your presentation text is handled in memory for the duration of a single run and is transmitted only between Google services (Apps Script and Google Translate), inside Google's infrastructure, which encrypts data in transit . Encryption at rest. The only value the add-on stores is your language selection, held in your own Google account's Apps Script user properties store, which Google encrypts at rest . The developer stores no Google user data at rest anywhere: it operates no server, database, log of content, or file holding it. Access control and least privilege. The add-on can act only on the presentation it is open in ( presentations.currentonly ) and only draw its interface inside the editor ( script.container.ui ). It requests no offline access and cannot reach other files, your Drive, or any other Google account data beyond the language selection described here. Google scopes the language-selection store to your account and to this add-on. No sprue.works staff can access any user's presentation content, translations, or settings, because none of it is ever transmitted to the developer. Credential handling. The OAuth tokens that authorize the add-on are issued to and held by Google's Apps Script runtime. The developer never receives, stores, or has access to your tokens or to your Google account credentials, and the add-on's code never reads them. Data minimisation and no third parties. Only the text and layout of the selection or slides you chose are read, and only when you run an action. The text goes solely to Google Translate through Apps Script's built-in LanguageApp service, within Google's infrastructure. The add-on uses no analytics, no third-party services, and no logging of presentation content. Incident response. If the developer becomes aware of a security incident affecting Google user data handled by the add-on, the developer will notify affected users and Google without undue delay, using the contact address at the end of this policy and the project's repository. Verifiability. The add-on's source code is public at github.com/sprue-works/polyglot-slides , so every statement here can be checked against the code that runs. AI/ML model training. The add-on does not use Google user data to develop, improve, or train generalized artificial intelligence or machine learning models. It does not retain the data needed to do so. Retention and deletion of Google user data Presentation content and translations are not retained after a run completes. The add-on keeps no copy of your presentations, your selected text, or the translations it produced; the translated copies exist only inside your presentation, where you control them. Your language selection (a list of language codes, no personal data) is retained in your account's Apps Script user properties so the sidebar remembers it. It is overwritten each time you run an action and is retained until you uninstall the add-on or revoke its access at myaccount.google.com/permissions , after which the add-on can no longer read it. Execution logs. Google may keep standard Apps Script execution logs (timestamps, error messages) for the add-on's script project, as it does for any add-on, and retains them under Google's own policy. These do not include your slide content or translations. To ask a question or make a request about your data, contact help@sprue.works . Children The add-on is intended for teachers and other adults. It does not knowingly collect any information from anyone, including children. Changes Changes to this policy are published at this address with an updated effective date.
